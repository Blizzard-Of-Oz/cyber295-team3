### Diagrams (Mermaid.js)

This directory contains architecture and flow diagrams written in **Mermaid.js** (`.mmd` files).  
Each file represents a single, self-contained diagram.

#### Viewing Diagrams
1. Copy the contents of a `.mmd` file.
2. Paste it into https://mermaid.ai/live/edit.
3. The diagram will be rendered automatically in the browser.

#### Exporting Diagrams
Once rendered, diagrams can be exported as **PNG** or **SVG** via the **Actions** menu.
